# Deployment artifacts

`initial-inspection-schedule.csv` is generated from `data/forms.json` by running `npm run generate:schedule`. Import it only after the target SharePoint list has a unique indexed `ScheduleKey` text column and the department routing table has been validated.

`sample-audit-report.html` is a deterministic rendering fixture generated by `npm run generate:audit`. It intentionally identifies missing corrective-action and workflow-history inputs and is not a complete regulatory audit package.

The live `QCMS Generate Audit Report` flow (`c534f2d7-8187-4cee-9a5e-b389ca6059f5`) now accepts Start Date and End Date inputs, applies those dates to Inspection Records and Inspection Responses queries, paginates both reads, creates an HTML response-detail table, and saves a timestamped artifact to the private `QCMS Reports` SharePoint library. Controlled run `08584176229210326038362205365CU12` generated `QCMS-Audit-2026-06-01-to-2026-07-13-20260713-230616.html` successfully. The live artifact does not yet contain Corrective Actions or Workflow History sections and must not be treated as the final regulatory package until those sections and their relationship filtering are implemented.
